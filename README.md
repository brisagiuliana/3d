# Papiweb Image to 3D Converter

Una aplicación web que convierte imágenes 2D en modelos 3D interactivos utilizando inteligencia artificial.

🌐 [Ver Demo en Vivo](https://brisagiuliana.github.io/3d/)

## Características

- Conversión de imágenes 2D a modelos 3D
- Visualización 3D interactiva
- Exportación a formato GLB
- Interfaz moderna con tema oscuro
- Procesamiento del lado del cliente

## Tecnologías

- Three.js para visualización 3D
- TensorFlow.js para procesamiento de IA
- JavaScript moderno (ES6+)
- HTML5 y CSS3

## Cómo usar

1. Selecciona una imagen de tu dispositivo
2. Haz clic en "Generate 3D Model"
3. Interactúa con el modelo 3D resultante
4. Descarga el modelo en formato GLB

## Desarrollo

Para ejecutar el proyecto localmente:

```bash
python3 -m http.server 8000
```

Luego abre `http://localhost:8000` en tu navegador.
